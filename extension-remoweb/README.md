# Extensión Chrome / Edge — GanaderIA RemoWeb (Autocompletado 1-Clic)

Esta extensión autorrellena en 1 clic los formularios de **Agroficina Virtual / RemoWeb** del Principado de Asturias a partir de la cola de trámites generada en **GanaderIA**, dejando siempre el control final de revisión y firma con Cl@ve / Certificado Digital al ganadero.

## Cómo instalarla en 1 minuto (Chrome o Microsoft Edge)

1. Abre Chrome o Edge y escribe en la barra de direcciones:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
2. Activa el interruptor **Modo de desarrollador** (arriba a la derecha o a la izquierda).
3. Pulsa **Cargar descomprimida** (*Load unpacked*) y selecciona esta carpeta: `extension-remoweb`.

*(Opcional para probar con el simulador local `simulador_remoweb.html`: entra en **Detalles** de la extensión y activa **Permitir el acceso a las URL de archivo**.)*

## Cómo usarla

1. En la app web **GanaderIA** → pestaña **Robot y RemoWeb**, pulsa **Copiar para Extensión Chrome** (o descarga el archivo JSON).
2. Abre el formulario correspondiente en **Agroficina Virtual / RemoWeb** (o haz doble clic en `simulador_remoweb.html` para probarlo ahora mismo).
3. Haz clic en el icono de la extensión **GanaderIA · RemoWeb**, pega el JSON, pulsa **Cargar trámites** y haz clic en **Rellenar en esta página**.
